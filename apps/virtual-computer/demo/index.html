Virtual Computer PoC

Desktop asli satu bot, disematkan dari control plane lewat proxy noVNC. Isi token dan bot id, lalu tekan Buka desktop.

Belum ada desktop yang dibuka.

Sesi tidak dibuat dari halaman ini: pastikan POST /v1/sessions dengan bot_id yang sama sudah dijalankan, dan control plane mendengarkan di 127.0.0.1:<port>. Token hanya dipakai untuk menyusun URL di atas dan tidak disimpan di mana pun.
